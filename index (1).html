Bitcoin Trader Sentiment Analysis

Investigated whether Bitcoin market sentiment (Fear/Greed Index) predicts individual trader outcomes, using 104K+ real closed trades from Hyperliquid matched against 2,644 days of sentiment data. Computer vision

Microscopy Blood Cell Classification

CNN classifier on 17K+ microscopy images, built on MobileNetV2 transfer learning. Replaced the standard Flatten head with GlobalAveragePooling2D — cutting head parameters roughly 250× and removing the overfitting that came with the larger head — and handled severe class imbalance with weighted training rather than naive oversampling.

Limitation acknowledged: trained on a single public microscopy dataset; would need validation against a different lab's imaging setup before any clinical-adjacent use.

Customer Churn Prediction

Designed a full, reproducible preprocessing pipeline for a mixed-type churn dataset: mean/median/most-frequent and KNN imputation matched to each field's missingness pattern, One-Hot and Ordinal encoding via ColumnTransformer, and StandardScaler feature scaling — wrapped into a single sklearn Pipeline so training and inference never drift apart.

Limitation acknowledged: project scope centers on pipeline design and reproducibility; model comparison across KNN/Decision Tree/Logistic Regression is a smaller, secondary part of the work.
